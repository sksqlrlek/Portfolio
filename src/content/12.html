상세 설명

추천 화면 요청 시 Controller가 likeRecList, popularRecList, genreSections 3개를 request scope에 담아 JSP로 전달합니다. movieCard.jsp를 jsp:include로 분리해 카드 컴포넌트를 재사용했습니다. 카드 앞면은 TMDB 포스터 이미지, 뒷면은 제목·개봉일·상영시간·평점·추천수·장르 pill을 표시합니다. 마우스 오버 0.5초 후 CSS rotateY(180deg)로 카드가 뒤집히며, 장르별 고유 색상 pill은 genre-${장르명} 클래스로 동적 매핑했습니다.캐러셀은 드래그 스크롤과 좌우 버튼을 지원하며, 중앙에서 멀어질수록 opacity와 blur를 점진적으로 적용해 포커스 카드를 시각적으로 강조합니다.
