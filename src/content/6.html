순수 Servlet 기반 FrontController 패턴으로 MVC를 직접 구현한 영화 정보 · 커뮤니티 웹 서비스 — TMDB API 배치 수집, 장르 기반 추천, 관리자 통계 대시보드까지 풀스택 구현

개발 주요 사항

  1. 01
    Servlet MVC

    FrontController + Action 인터페이스로 MVC 패턴 직접 구현 (프레임워크 없이 .do URL 라우팅, Properties 기반 Command 매핑)

  2. 02
    외부 API와 배치

    TMDB API 멀티스레드 배치 처리로 영화/배우 데이터 자동 수집 (ExecutorService 병렬 처리, 청크 단위 트랜잭션, 재시도 로직)

  3. 03
    싱글톤 패턴

    싱글톤 패턴으로 AppConfig · DBService · DAO 계층 일관 관리 (SqlSessionFactory 단일 인스턴스, XML 설정 로더 스레드 세이프 구현)

  4. 04
    영화 추천

    회원 기반 선호 장르 추천 시스템 구현 (비로그인 랜덤 → 로그인 시 선호 장르 → 장르별 섹션 그룹핑)

기술 스택

  • Java 21
  • Servlet/JSP
  • MyBatis 3.5
  • Oracle DB
  • Maven
  • Chart.js
  • Tomcat 10
