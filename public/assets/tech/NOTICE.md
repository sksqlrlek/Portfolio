# 기술 로고 출처

이 폴더의 SVG는 [devicon](https://github.com/devicons/devicon) v2.16.0의 `*-original.svg`를 그대로 내려받은 파일입니다.

- devicon 라이선스: MIT
- 각 로고의 상표권은 해당 기술의 소유자에게 있습니다.
- 외부 CDN 없이 사이트 안에서 제공하려고 복사했습니다. 새 로고가 필요하면 같은 버전에서 `icons/<이름>/<이름>-original.svg`를 받아 `<이름>.svg`로 저장하세요.

## 추가한 로고 (2026-11-13)

- `jwt.svg`, `flyway.svg`, `hibernate.svg`, `tomcat.svg`, `chartjs.svg`: devicon v2.18.0의 `*-original.svg` (MIT). v2.16.0에는 없는 아이콘입니다.
- `mybatis.svg`: MyBatis 공식 사이트 로고(`https://mybatis.org/images/mybatis-logo.png`)에서 새 그림만 잘라 SVG 안에 PNG로 담았습니다.
- JPA는 기술 명세라 공식 로고가 없어, 실제 구현체인 Hibernate 로고를 쓰고 이름을 `JPA (Hibernate)`로 표시합니다.
