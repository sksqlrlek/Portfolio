Spring Boot · React 기반 통합 그룹웨어 — AA 역할로 공통 아키텍처 설계부터 화상회의 AI 회의록 자동생성, 실시간 알림·메신저 등 10개 이상 도메인 풀스택 구현

개발 주요 사항

  1. 01
    팀 공통 아키텍처

    AA로서 백엔드 공통 아키텍처 설계 및 협업 가이드 작성·배포로 4인 팀 개발 표준 정립

  2. 02
    AI 회의록과 전자결재

    LiveKit 녹취 → Whisper STT → LLM 회의록 자동 생성 → 전자결재 기안까지 자동화 구현 (팩토리 메서드 + 템플릿 메서드 패턴)

  3. 03
    이벤트 기반 실시간 알림

    @TransactionalEventListener + @Async 이벤트 아키텍처로 SSE 실시간 알림 시스템 구현

  4. 04
    그룹웨어 기능 구현

    대시보드 12종 위젯, 6개 도메인 통합검색, WebSocket 메신저, 공휴일 API 연동 등 다수 도메인 추가 구현
