근거 기반 회의록 생성 구조

AI 회의록 생성 시 실제 회의에서 발화되지 않은 내용을 임의로 보완하는 환각 문제가 발생할 수 있다고 판단했습니다. 이를 방지하기 위해 프롬프트를 [ROLE]·[RULES]·[REFERENCE]·[OUTPUT FORMAT] 구조로 분리하고, 회의 대화 로그만 근거로 사용하도록 제한했습니다.

특히 REFERENCE 정보는 참고용으로만 사용하고, 회의록 본문에는 발화 로그에 존재하는 내용만 반영하도록 설계했습니다. 또한 결과 형식을 HTML 구조와 {SIGN:N} 서명 토큰으로 고정하여 전자결재 문서로 바로 전달할 수 있도록 했습니다.

AI 초안 → 전자결재 연동 → 회의 후속 업무 자동화

회의 종료 후 생성된 AI 회의록 초안은 담당자 검토 단계를 거쳐 전자결재 기안 문서로 전환되도록 설계했습니다. 초안 상태는 01. AI초안 → 02. 편집중 → 03. 결재요청 흐름으로 관리하여, AI가 생성한 결과를 그대로 확정하지 않고 사람이 검토한 뒤 결재 프로세스로 넘기도록 했습니다.

이를 통해 회의 녹취, STT 변환, LLM 회의록 생성, 담당자 검토, 전자결재 기안까지 이어지는 후속 업무를 하나의 자동화 파이프라인으로 연결했습니다.
